# 東美発注（iPad用・オフライン発注アプリ）v1.6.0

## 入っているファイル

| ファイル | 内容 |
|---|---|
| index.html | 画面 |
| app.js | アプリ本体 |
| sw.js | オフラインで動かすための仕組み（Service Worker） |
| manifest.json / icon-192.png / icon-512.png | ホーム画面に追加したときの名前とアイコン |
| zxing.min.js | カメラでバーコードを読むための部品 |
| html2canvas.min.js / jspdf.umd.min.js | 発注書のPDFを作るための部品 |
| data/products.json | 初期の商品マスタ（47,489件・2026/11/20統合版） |
| data/seed.json | 仕入先26社の設定・店舗情報・ブランド別掛率 |

## 1. GitHub Pages に置く

1. GitHub で新しいリポジトリを作ります（例：`tobi-hacchu2`）。
   - 以前の発注アプリとは別のリポジトリにしてください。データの保存場所が混ざらないようにするためです。
2. このZIPの中身（フォルダごと全部）を、リポジトリのいちばん上にアップロードします。
   - 「Add file」→「Upload files」で、`data` フォルダもそのままドラッグして大丈夫です。
3. 「Settings」→「Pages」で、Branch を `main` / `(root)` にして Save します。
4. 数分たつと `https://（アカウント名）.github.io/tobi-hacchu2/` で開けるようになります。

## 2. iPad に入れる

1. iPad の **Safari** で上のURLを開きます。
2. 初回だけ「初回データを準備しています」と出て、数秒〜数十秒かかります（商品約4万7千件をiPadに保存しています）。
3. 共有ボタン →「ホーム画面に追加」で、アプリのように使えます。
4. 一度開けば、そのあとはインターネットにつながっていなくても使えます。

## 3. 最初にやること

- 「設定」→「担当者」で、発注するスタッフの名前を登録してください（登録しないと発注を確定できません）。
- 「設定」→「仕入先」で、FAX番号・メールアドレス・取引先コードを確認・修正できます。

## 4. 使い方

- **発注**：上で部門（画材／額縁・木枠・キャンバス・金具）を選び、仕入先のタブを選んで数量を入れます。
  - ＋ボタンは取り寄せ単位ごとに増えます（ホルベイン・バニーコルアート・ターレンス・ターナー・福井金属）。端数を手で入れると注意が出ます。
  - 数量を入れると「備考」欄が出ます（客注のお名前・日付など）。発注書の備考欄に載ります。
  - 送料無料ラインまでの残りが上に出ます。下代基準の仕入先は「上代×掛率」の目安です。
- **取扱中**：店で扱っている商品には緑の「取扱中」が付き、一覧の上に表示されます。「取扱中のみ」で絞り込めます。印は商品マスタの編集画面で付け外しできます。
- **バーコード**：「バーコード読取」でカメラが起動します（初回はカメラの許可が必要）。続けて読み取れます。
  - USB・Bluetoothのバーコードリーダーは、検索欄に読ませてEnterでも追加できます。
  - 登録されていないJANは、その場で商品登録できます。
  - 同じJANの商品が複数あるときは、候補から選びます。
- **通信欄**：下の「通信欄」ボタンで、その発注だけの追加コメントを入れられます（いつもの文の下に追加されます）。発注確定の画面でも入力・修正できます。
- **発注確定**：担当者を選んで「発注確定」→ 発注書が表示されます。
  - 「PDF・印刷」：発注書のPDFを作り、iPadの共有画面を開きます。そこから「プリント」で印刷、「メール」でPDFを添付して送信、「ファイルに保存」などが選べます。
    （共有画面が出ないときは、ボタンが「PDFを共有（印刷・メール）」に変わっているので、もう一度押してください）
- **履歴**：過去の発注書をもう一度表示・印刷したり、「再発注」で同じ内容を発注中に入れたりできます。担当者・仕入先・月で絞り込めます。
- **商品マスタ**：商品の行をタップすると編集・削除できます。追加やCSVの読込・出力もここでできます。

## 5. 商品マスタをあとから追加・更新する

**おすすめ**：メーカーからもらったExcelを Claude に渡して、アプリ取込用CSVにしてもらいます（形式がバラバラでも対応できます）。

**自分で取り込む場合**：「商品マスタ」→「CSV読込」。次の列名に対応しています（順番は自由、ない列は空のまま）。

`部門, 仕入先, メーカー, JAN, 品番, 商品名, 単位, 取り寄せ単位, 上代, 下代, 掛率, 状態, 要確認, 取扱中`

- 空欄のセルは今の値を変えません（例：掛率だけ入ったCSVなら掛率だけ更新）。「取扱中」は ○ で印を付け、× で外します。

- 「仕入先」列がないCSVは、読み込むときに仕入先を選べます。
- 同じ仕入先の中で、JAN（ないときは品番）が同じ商品は上書き、それ以外は追加になります。
- ほかの仕入先と同じJANの商品があると、一覧で知らせます。
- 「CSV出力」で出したファイルは、そのままひな形として使えます。

## 6. バックアップ（大切）

データはiPadの中だけに保存されています。iPadの故障や「Safariの履歴とWebサイトデータを消去」で消えてしまいます。
月に1回くらい、「設定」→「バックアップを保存」でファイルに保存してください。共有画面が開くので「ファイルに保存」を選びます（iCloud Driveがおすすめです）。
前回のバックアップから30日たつと、アプリを開いたときにお知らせが出ます。「あとで」を押すと3日後にもう一度お知らせします。
「バックアップから戻す」で、そのときの状態に戻せます。別のiPadへの引っ越しにも使えます。

## 7. アプリを更新したとき

ファイルを差し替えたら、`sw.js` の1行目付近の `tobi-hacchu-v7` を `v8` のように変えてからアップロードしてください。iPadでアプリを開き直すと新しい版になります（2回開き直す必要があることがあります）。
商品マスタや発注履歴は、アプリを更新しても消えません。

## 8. 決めごとのメモ

- 下代の目安は「商品ごとの掛率 → ブランド別の掛率（丸善の6ブランドなど）→ 仕入先の基本掛率」の順に使います。正確な仕入値ではないため、発注書の通信欄に「送料がかかる場合はご連絡お願い致します。」を初期文として入れています。
- 発注書は1枚30行で、超えると自動で次のページに続きます。合計と通信欄は最後のページに入ります。
- 発注番号は「H-年月日-連番」（例：H-20261121-001）です。
- 単位「ケ」は「個」と表示しています。
- 商品マスタに無い仕入先（クサカベ・マルマン・ミューズなど）は、「＋商品を登録」で手入力できます。
